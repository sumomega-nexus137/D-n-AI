# D-n-AI — AgriTech AI Hackathon (Трек 3: компьютерное зрение в агрономии)

Прототип: веб-сайт + Telegram-бот, определяющий по фото:

1. **Модуль 1 (главный):** качество зерна пшеницы по фото пробы — доли зёрен
   по категориям (целое здоровое / битое-повреждённое / щуплое-мелкое /
   проросшее / примесь), предварительный класс зерна, экономический эффект
   в тенге.
2. **Модуль 2:** распознавание болезней/сорняков пшеницы и ячменя по фото
   листа/растения.

Плюс: голосовые сообщения в Telegram (казахский/русский) — пересылаются
напрямую в Gemini Flash API без собственного распознавания речи.

## Статус

🚧 В разработке (хакатон, дедлайн 21.09.2026).

**Готово:** сбор и разметка датасетов, извлечение эмбеддингов DINOv2,
обучение и валидация обеих голов-классификаторов, OpenCV-сегментация
зёрен, сравнение с Gemini zero-shot.
**В работе:** backend, веб-интерфейс, Telegram-бот, деплой.

## Результаты

- **Модуль 1 (качество зерна):** accuracy 98.84%, macro-F1 0.9884 на
  held-out тесте (5 классов).
- **Модуль 2 (болезни/вредители/сорняки):** accuracy 85.71%, macro-F1
  0.854 на held-out тесте (24 класса).
- **Сравнение с Gemini (zero-shot, без дообучения):** наша
  специализированная модель точнее определяет повреждённость/битость
  зерна — ключевую метрику задачи 3.3 — и не уступает Gemini в
  распознавании болезней листа по фото.

Подробности обучения — `docs/TRAINING_RESULTS.md`, сегментация —
`docs/SEGMENTATION.md`.

## Архитектура

Фото → (только Модуль 1: OpenCV-сегментация зёрен, классический метод, без
нейросети) → замороженный **DINOv2** (готовые веса, без дообучения) →
эмбеддинг → лёгкая голова-классификатор (LogisticRegression/XGBoost,
обучается на эмбеддингах) → агрегация результата.

## Датасеты

**Модуль 1 (зерно):** [GrainSet](https://github.com/hellodfan/GrainSet)
(Nature Scientific Data, 2023) — 200K фото зерна пшеницы, CC BY 4.0.

**Модуль 2 (болезни/вредители/сорняки):**
- `kushagra3204/wheat-plant-diseases` и `olyadgetch/wheat-leaf-dataset` (Kaggle) — болезни и вредители пшеницы
- `vbookshelf/v2-plant-seedlings-dataset` (Kaggle) — сорняки

Подробности, объёмы, лицензии источников и таксономия классов —
`docs/DATASETS.md`.

## Структура репозитория

```
backend/            FastAPI backend (два эндпоинта: модуль 1 и модуль 2)
  app/
    module1_grain/  логика модуля "качество зерна"
    module2_disease/ логика модуля "болезни/сорняки"
    common/         общий код (загрузка моделей, DINOv2, эмбеддинги)
webapp/             веб-интерфейс (Streamlit/Gradio)
bot/                Telegram-бот
notebooks/          код для Google Colab (извлечение эмбеддингов, обучение голов)
data/               датасеты (не в git, см. .gitignore) + инструкции по скачиванию
models/             обученные головы-классификаторы (веса, не в git)
scripts/            вспомогательные скрипты (подготовка данных и т.п.)
tests/              тесты
docs/               документация проекта (датасеты, таксономия классов и т.д.)
```

## Установка и запуск (локально)

```bash
git clone <repo-url>
cd D-n-AI
python -m venv .venv && source .venv/bin/activate
pip install -r backend/requirements.txt
cp .env.example .env   # заполнить GEMINI_API_KEY и т.д.
uvicorn backend.app.main:app --reload
```

Подробная инструкция запуска backend/веб-интерфейса/бота будет дополнена по
мере готовности.

## Переменные окружения

См. `.env.example`. Ключ Gemini и токен Telegram-бота никогда не хранятся в
коде — только в `.env` (локально) или в Secrets/Environment Variables
хостинга (Hugging Face Spaces / Render) при деплое.
