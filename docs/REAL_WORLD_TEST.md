# Проверка на реальных фото (не из тренировочных датасетов)

Прогнали весь пайплайн (сегментация → DINOv2 → голова) на 5 случайных фото
из интернета, не связанных ни с одним из наших датасетов — честная проверка
генерализации, а не просто метрика на held-out тесте того же источника.

## Модуль 1: качество зерна

| Фото | Найдено зёрен | Результат | Оценка |
|---|---|---|---|
| Дроблёная пшеница (Cracked Wheat) | 1014 | 97.6% битое-повреждённое | ✅ верно — дроблёная пшеница и есть битое зерно |
| Фото-сравнение 3 колонок (целое/повреждённое/дроблёное) | 259 | ~40% битое, ~39% целое, ~18% проросшее | ✅ разумно — на фото реально смешаны разные состояния |
| Булгур (обработанный продукт) | 631 | ~40% целое, ~33% примесь, ~22% битое | ⚠️ смешанно — булгур пропарен/обработан, визуально далёк от сырых зёрен GrainSet |

## Модуль 2: болезни/вредители/сорняки

| Фото | Результат | Оценка |
|---|---|---|
| Лист с мучнистой росой (крупный план) | **99.7% Mildew** | ✅ точное попадание |
| Сорняк-осот в поле пшеницы (общий план) | 98.5% Common Root Rot (сорняков нет даже в топ-5) | ❌ неверно |

## Вывод

- Классификация болезней по крупному плану листа — работает отлично,
  ровно так, как задумано (99.7% на реальном фото не из датасета).
- Классификация зерна — работает хорошо на "сыром" зерне, менее уверенно
  на сильно обработанных продуктах (булгур) — ожидаемый domain gap.
- **Классификация сорняков работает только на крупном плане самого
  растения** (как в тренировочных данных Plant Seedlings Dataset — молодые
  ростки на грядке), но не на общих кадрах поля с сорняком на фоне спелой
  пшеницы. Это реальное ограничение прототипа, а не баг: тренировочные
  данные и этот тип фото визуально сильно различаются (крупный молодой
  росток на голой земле vs. взрослое цветущее растение на фоне тысяч
  колосьев).

**Рекомендация для демо**: показывать распознавание сорняков на **крупном
плане самого растения** (что кстати соответствует формулировке задачи
"фото с телефона" — предполагается, что пользователь фотографирует
конкретное растение, а не снимает поле с высоты), не на широких кадрах
поля. Указать это ограничение явно в презентации как честную оговорку, а
не пытаться скрыть.
