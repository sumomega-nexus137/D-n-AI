🌾 Dän-AI

Агроскан по фото — качество зерна и здоровье растений за секунды

Карманный советник по партии зерна для фермеров Казахстана. Анализ по фото, ориентир по цене, конкретное действие.

⚡ Запустить в Google Colab (бесплатно) 📖 Запустить локально
💡 Для судей хакатона: нажмите кнопку "Запустить в Colab" выше → откроется Google Colab → нажмите "Run all" → через 1-2 минуты получите работающий сайт и Telegram-бота с публичной ссылкой.

🌾 Качество зерна

По фото пробы: доли по категориям, предварительный класс, цена в тенге за тонну и рекомендации — что сделать с партией и сколько это даст денег.

🍃 Болезни растений

По фото листа: диагноз (24 класса), что это, что делать, срочность. При низкой уверенности честно говорит, а не выдаёт случайный класс за факт.

🤖 ИИ-консультант

Чат на сайте и в Telegram-боте. Можно спросить голосом на казахском или русском — Gemini распознаёт речь и отвечает практичным советом.

Технологический стек

ML-модель DINOv2 ViT-S/14 + LogisticRegression (98.8% accuracy)
Computer Vision OpenCV сегментация, watershed
Backend FastAPI, PyTorch (CPU), scikit-learn
Frontend Vite + React + Tailwind + Three.js
Bot python-telegram-bot v21
AI Google Gemini 2.5 Flash
📊 Метрики:
  • Качество зерна: accuracy 98.8%, macro-F1 0.988 (5 классов)
  • Болезни/сорняки: accuracy 85.7%, macro-F1 0.854 (24 класса)
  • Скорость анализа: 3–5 секунд на обычном CPU
